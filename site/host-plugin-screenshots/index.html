Host Plugin Packages: external project, run in the macOS host window

Both packages are packed. The companion is installed globally with npm i -g into a temp prefix. lights is scaffolded outside the repo with vitadeck create lights --host-plugin.

1. The Shell's link hint names the global CLI

2. The demo app uses the built-in systemStats; capabilities list the installed lights plugin

3. After vitadeck-host-companion install dist/lights.vdplugin.zip, the scaffolded app calls its own plugin, which reads files/motd.txt from its package

4. Under npm run host (--plugin ./dist), edit host/files/motd.txt and run vitadeck build: the companion reloads with no restart

5. After vitadeck-host-companion remove lights, the app gets unknown_plugin
